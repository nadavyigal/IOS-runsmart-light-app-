How do pilot athletes get v2?

v1.3 turns v2 on only in TestFlight builds. With D4 (coach and athlete both need v2), every pilot athlete must install TestFlight. Beginner runners often won't.

A. TestFlight only (v1.3 as written)

  • Zero risk to App Store users
  • Every athlete installs TestFlight and keeps it updated
  • Coach roster can fill with "needs the latest RunSmart"

B. Dark in the App Store build CHOSEN

  • v2 ships in the App Store build, switched off
  • A server allowlist turns it on per pilot coach (new table coach_v2_pilot_coaches)
  • Athletes just update the app
  • Cost: one extra condition in C7.0

You picked B. C7.0 ships the per-coach allowlist empty, with three tests: unlisted coach = off, listed coach = on, kill switch = off everywhere. You add each pilot coach to the list after TF-1a passes.

S2 · S3

Push no longer blocks coach value
